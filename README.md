# CineBook – Movie Ticket Booking System

## Project Overview

CineBook is a Java-based movie ticket booking application that allows users to view movie shows, check seat availability, book tickets, calculate ticket prices, and cancel bookings through a console interface.

## Problem Statement

Manual movie ticket booking can make seat availability tracking, ticket price calculation, and booking cancellation difficult. CineBook aims to simplify these operations using Java.

## Proposed Solution

CineBook provides a menu-driven system for managing movie shows, seat bookings, ticket pricing, viewing booked seats and cancellations.

## Features

- View movie shows&#x20;
- Display a 3 x 5 seat map
- Identify available and booked seats
- Book multiple seats
- Calculate ticket prices based on seat categories
- Cancel bookings;
